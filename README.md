# Гибридные рекомендательные системы с мультимодальными признаками

Учебно-исследовательский проект по рекомендательным системам на датасетах
**MicroLens-100K** и **VK-LSVD**.

Проект основан на задаче VK Education по исследованию влияния контентных
представлений на качество гибридных рекомендательных систем.

## Актуальность темы

Современные рекомендательные системы используют не только историю
взаимодействий пользователей с объектами, но и дополнительную информацию
о самих объектах.

К такой информации могут относиться:

- текстовые признаки
- изображения
- мультимодальные представления
- заранее рассчитанные контентные эмбеддинги

Надежность коллаборативного сигнала может различаться для разных объектов.

Если по объекту накоплено большое количество взаимодействий, модель способна
получить достаточно информации из пользовательского поведения.

Для редких объектов доступно меньше коллаборативной информации, поэтому
контентные представления могут компенсировать её недостаток и повысить качество рекомендаций.

В рамках проекта рассматривается вопрос:

> Требуется ли одинаковый объём контентной информации для объектов с различной надёжностью 
> коллаборативного сигнала?


## Цель проекта

Целью проекта является исследование эффективности адаптивного использования контентных представлений 
в гибридных рекомендательных системах с учётом надёжности коллаборативного сигнала.

## Задачи проекта
1. Провести анализ структуры и характеристик датасетов **MicroLens-100K** и **VK-LSVD**, включая 
распределение пользовательских взаимодействий, разреженность данных и доступные контентные представления.

2. Разработать единый протокол подготовки данных и оценки рекомендательных моделей, обеспечивающий 
корректное разбиение выборки, отсутствие утечки данных и сопоставимость результатов экспериментов.

3. Реализовать базовые коллаборативные рекомендательные модели для формирования исходного уровня 
качества без использования контентных признаков.

4. Оценить влияние различных типов контентных представлений на качество рекомендаций на 
датасете **MicroLens-100K** при использовании текстовых, визуальных и мультимодальных признаков.

5. Исследовать зависимость полезности контентного сигнала от надёжности коллаборативного сигнала, 
определяемой по доступной истории взаимодействий с объектами.

6. Исследовать влияние размерности контентного представления на качество рекомендаций на 
датасете **VK-LSVD** при использовании различного числа компонент эмбеддинга.

7. Разработать и экспериментально оценить адаптивную стратегию выбора объёма контентного представления 
с учётом надёжности коллаборативного сигнала и сравнить её с использованием фиксированной размерности.


## Структура исследования


## Часть 1. MicroLens-100K

На датасете MicroLens-100K планируется сравнить:

- коллаборативную модель без контентных признаков;
- CF + Text;
- CF + Image;
- CF + Text + Image.

Основной исследовательский вопрос:

> Одинаково ли полезны различные виды контента для популярных и редких объектов?

Дополнительно будет исследована зависимость прироста качества от количества
взаимодействий с объектом.


## Часть 2. VK-LSVD

На датасете VK-LSVD будет исследован готовый контентный эмбеддинг размерности 64.

Планируется сравнить использование первых:

- 8 компонент;
- 16 компонент;
- 32 компонент;
- 64 компонент.

Основной исследовательский вопрос:

> Нужна ли одинаковая размерность контентного представления всем объектам?

Предполагается проверить адаптивную стратегию, при которой объём используемого
контента зависит от надёжности коллаборативного сигнала.


## Основные этапы

1. Анализ данных.
2. Выбор корректного разбиения на train / validation / test.
3. Реализация простых базовых моделей.
4. Коллаборативная фильтрация.
5. Добавление текстовых и визуальных признаков.
6. Анализ качества для объектов с различным количеством взаимодействий.
7. Эксперименты с размерностью эмбеддингов VK-LSVD.
8. Адаптивный выбор размерности.
9. Абляционные эксперименты.
10. Финальная оценка и отчёт.


## Метрики

Основные метрики качества:

- Recall@K;
- NDCG@K.

Конкретные значения K и окончательный протокол оценки будут выбраны
после анализа структуры данных.
