# Данные, используемые в проекте

Исходные датасеты не хранятся в репозитории.
В проекте используются два набора данных:

## MicroLens-100K

Используется для исследования влияния текстовых, визуальных
и мультимодальных контентных представлений.

Официальный источник:
https://recsys.westlake.edu.cn/

## VK-LSVD

Используется для исследования влияния размерности контентного
представления и адаптивного выбора числа компонент.

Официальный источник:
https://huggingface.co/datasets/deepvk/VK-LSVD
